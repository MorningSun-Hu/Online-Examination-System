# web

Vite + TypeScript 双入口：`teacher.html`、`student.html`。共享 `src/shared/api.ts`。

## 讲台 `src/teacher/`

五模块：题库、班级名册、试卷、任务、成绩分析。有右侧详情的列表点整行选中；删除放选中项标题栏。名册多选批量删除。必要结果用 `#notice-host` 对话框。

任务分当前/历史。名单用筛选 +「全选可见」勾选，保存按钮在标题栏。保存名单成功码为 200。

成绩分析：左历史任务，右默认数据大屏；点 KPI/图表进学生成绩或题目分析。题目按大题折叠，标题带正确率、得分率、均分。

## 学生 `src/student/`

入口如一张试卷：标题、总分/时间、班级/姓名/学号。作答 15 秒保存。考试提交后只显示已提交；练习立即出分析。公开后 `resultHtml` 对单选/多选列出选项，并标「你的选择」「正确答案」。
