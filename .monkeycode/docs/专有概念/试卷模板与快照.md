# 试卷模板与快照

**试卷模板**（表 `exam_papers`）是教师组好的可复用卷面规则：题库、题量或 `bank_draws`、乱序开关、`score_plan_json`、总分与及格分。讲台「试卷管理」创建、预览、在预览里调分。

**任务**通过 `exam_tasks.paper_id` 引用模板。创建任务时把规则复制进 `paper_rules`。学生每次作答再生成 **试卷快照**（表 `papers.items_json`）：题序、选项映射、每题分值。考试中途重进复用同一快照；练习再次进入生成新快照。

预览接口关闭乱序抽题，便于教师按题型顺序核分值。正式考试仍可按规则重抽，但题目分值用试卷已存 `score_plan`。

历史任务（`closed` / `graded` / `released`）详情仍展示答卷入口，公开后学生用同一地址领取分析。
