# 分值方案

分值在组卷时计算并写入 `exam_papers.score_plan_json`，任务不再单独调分。讲台在试卷预览每道大题标题旁内联改分，失焦保存（`PATCH /api/teacher/papers/{id}`）。

算法在 `paper-gen::allocate_scores`：

1. 总分 `T` 必须 `>=` 题量 `N`，否则拒绝。
2. 有题型小计且之和等于 `T`：按题型分配。
3. 有小计但之和不等于 `T`：按比例缩放到 `T` 后再分配。
4. 未给小计：按题量比例分到各题型，余数落在最后一种题型。
5. 同一题型内：每题先得整数商，余数加在该题型 **最后** 几题。
6. 若出现 0 分题，从分值最高的题借 1 分。

生成学生快照时叠加已存 `score_plan`，保证考试抽题后每题分值与试卷模板一致。
