# 任务状态

| 状态 | 含义 | 讲台分区 |
|---|---|---|
| `draft` | 草稿，可改名单、拆班、删除、发布 | 当前任务 |
| `published` | 进行中，可收卷、改提前交卷 | 当前任务 |
| `closed` | 已收卷 | 历史任务 |
| `graded` | 已批改 | 历史任务 |
| `released` | 已公开，学生可看分析 | 历史任务 |

历史任务不可发布、收卷、拆分子任务；详情仍显示答卷入口。

草稿且覆盖多个班级时可 `POST .../split`：按班生成子任务后删除原任务。

作答记录 `attempts.status`：`in_progress` / `submitted`。监控把名单映射为未进入、作答中、已提交。
