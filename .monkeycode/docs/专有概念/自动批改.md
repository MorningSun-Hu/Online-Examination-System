# 自动批改

客观题（单选、多选、判断）只要参考答案非空就自动批改，不受开关影响。任务字段 `exam_tasks.auto_grade` 只控制填空题是否按参考答案自动出分。试卷模板 `exam_papers.auto_grade` 只提供默认值，创建任务时可覆盖。编程题始终手工。

## 何时手工给分

`needs_manual` 为真则该题走给分台，分数写入 `AnswersBlob.code_scores`：

- 编程题始终手工
- 参考答案为空始终手工
- 任务关闭 `auto_grade` 时，填空题也手工

## 默认值

- 组卷默认打开（填空自动批）
- 已有库列迁移 `DEFAULT 1`
- 按班拆分子任务复制父任务的 `auto_grade`

## 开关

`PATCH /api/teacher/tasks/{id}` 可改 `auto_grade`。已公开（`released`）返回 409。打开后按参考答案重判已交填空，忽略这些题上的手工分，并清除 `marking_confirmed`。关闭后不把旧自动分拷进 `code_scores`，须重新给分。客观题不因开关重走给分台。

讲台打开开关时弹出确认：填空不完全匹配参考答案可能错判。

## 确认与公开

有待手工题的答卷须教师点色块给分，再对该生点「提交」写入 `marking_confirmed`。改分会取消确认。无待手工题则无需确认。

公开试卷要求：任务已结束（`closed` 或 `graded`），且全部待手工题都已给分并确认。结束任务后若已无待确认，状态自动变为 `graded`；再关掉自动批改（使填空回到待确认）可回到 `closed`。
