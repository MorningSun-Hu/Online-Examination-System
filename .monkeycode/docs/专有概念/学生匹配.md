# 学生匹配

进入考试时用班级、姓名、学号在当前任务名单中解析到唯一 `student_id`。

实现见 `crates/exam-server/src/student.rs` 的 `match_student`：

1. 提供学号：按学号命中；若同时给班级或姓名，必须与该行一致。
2. 只提供姓名：按姓名命中，可选再过滤班级；0 人 403；多人 409 要求改填学号。
3. `class_name` 可空。学生页单班任务会带出班级；姓名或学号填一出另一（`GET /api/student/lookup`）。

名单范围：`task_roster` 有人则只匹配名单；空名单回落到全库 `students`。身份不全时学生页不展示试卷。

当场会话绑定 `client_id`。同一学生从另一台机器重进，后续作答接到最新通过校验的客户端，快照与已答内容继续用。
