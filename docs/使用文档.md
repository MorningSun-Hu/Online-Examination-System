# 教室在线考试系统 · 使用文档

讲台在教师机浏览器打开。学生用教室局域网里的电脑或平板打开学生页。本机不需要外网。

设计说明见 [设计文档.md](./设计文档.md)。题库文件格式见 [题库规范化格式.md](./题库规范化格式.md)。

## 1. 启动

在项目根目录：

```bash
# 构建前端并启动服务（教室演示）
./scripts/start-teacher.sh run
```

开发（后端 + 前端热更新）：

```bash
./scripts/start-teacher.sh dev
```

Windows 使用 `scripts/start-teacher.bat`。

手动等价：

```bash
cd web
npm install
npm run build
cd ..
EXAM_WEB_DIR=./web/dist cargo run -p exam-server
```

默认地址 `http://本机IP:8080`。数据文件 `./data/exam.db`。

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `EXAM_DATA_DIR` | `./data` | 数据目录 |
| `EXAM_BIND` | `0.0.0.0:8080` | 监听地址 |
| `EXAM_WEB_DIR` | `web/dist` 等 | 静态页目录 |

健康检查：浏览器或 `curl http://127.0.0.1:8080/api/health`，应返回 `ok`。

## 2. 教师首次使用

1. 打开 `http://本机IP:8080/teacher.html`（或 `/teacher`）。
2. 第一次进入会要求设置讲台口令，之后用该口令登录。
3. 首页会列出本机局域网 IPv4，把学生入口念给学生，例如 `http://192.168.1.10:8080/student.html?t=任务ID`。
4. 讲台左侧六个模块：**题库管理**、**班级名册**、**试卷管理**、**任务管理**、**试卷批改**、**成绩分析**。

考试任务名称过长时，列表、详情标题和学生顶栏显示摘要，鼠标移上去可看全名。试卷批改左侧任务栏加宽，状态不换行。

## 3. 题库管理

用途：导入或编辑题目，供组卷抽取。

**导入 HTML**

1. 准备符合 [题库规范化格式.md](./题库规范化格式.md) 的 UTF-8 HTML。
2. 在题库管理中创建题库（或选中已有题库）。
3. 导入 HTML。整文件无法解析会失败且不写库；部分题目有错时，正确的题入库，失败题出现在导入报告里。

**导出**

选中题库后导出，得到规范黑白 HTML。下载文件名使用题库名。答案行为黑体加粗纯黑，便于打印。

**在页面上改题**

可增改删单题。题目已被已发布考试的试卷快照引用时，不能删除。

题型：单项选择、多项选择、判断、填空、编程。填空参考答案里的函数调用括号（如 `print("Hello")`）会按原样保存。

## 4. 班级名册

1. 先建班级。
2. 下载 CSV 模板，表头必须含「班级」「学号」「姓名」，UTF-8。
3. 导入。缺字段的行会跳过，报告里有行号。相同学号后导入的行覆盖姓名与班级。
4. 也可逐条登记、多选批量删除、导出名册。

任务名单只能从已导入学生中勾选。

## 5. 试卷管理

先组卷，再派任务。分值在试卷上调整，不在任务里改。

**新建试卷**

1. 填标题、总分；及格分留空则为总分的 60%。
2. 填写各题型题量。
3. 选择题库。每个题库可填抽题数量或比例；都留空则只按题型题量混合抽取。若填写，勾选的题库都要填，且数量之和等于各题型题量之和。
4. 可选：题型内乱序、选项乱序。
5. **智能实时组卷**默认不勾选：
   - 不勾选：创建时生成一份**固定试卷**，所有考生同一卷面。
   - 勾选：每次预览和每位考生都重新抽题。

题量超过题库存量时组卷失败，试卷不会生成。

**自动批改**

单选、多选、判断只要有参考答案就自动批改，没有开关。默认勾选「自动批改填空题」；关闭后填空要在试卷批改里手工给分。参考答案为空的题目始终手工。编程题始终手工。打开填空自动批改时需确认：学生答案与参考不完全一致可能错判。

**调分**

选中试卷后右侧预览。预览按题型顺序、关闭乱序，便于核对。在大题标题旁改分，失焦即保存。每题至少 1 分，总分不能小于题量。

## 6. 任务管理

**新建任务**

1. 选择已组好的试卷（没有试卷时先去试卷管理）。
2. 选择考试或练习。
3. 设定时长（正整数分钟）、是否允许提前交卷、是否自动批改填空题（默认跟随所选试卷）。
4. 在草稿状态勾选参与学生（可用筛选 +「全选可见」）。保存名单成功即可。
5. 覆盖多个班级时，可按班拆成多个子任务。

| 模式 | 学生侧 |
|---|---|
| 考试 | 提交一次；公开前看不到分数和答案 |
| 练习 | 可重复作答；提交后立即看到对错 |

**状态与按钮**

| 状态 | 可做的事 |
|---|---|
| 草稿 | 改名单、拆班、删除、发布 |
| 进行中 | 监考、改提前交卷、改填空自动批改、收卷、结束任务 |
| 已结束 / 已批改 / 已公开 | 出现在历史任务；详情仍有答卷入口 |

发布后名单冻结。收卷只提交正在作答的学生，任务继续。点结束任务后进入历史。已公开后不能再改自动批改。学生交卷或收卷后，成绩分析即可按当前数据出图，并可查看已交学生的试卷。

监控三列：未进入、作答中、已提交。点学生可查看其答卷；卷面顺序与该生答题时一致。

## 7. 试卷批改

左侧选任务，中间选学生，右侧给分台。

1. 点色块即给该题记分（0 到满分）。
2. 给完该生全部待批改题后点「提交」，确认这份答卷。改分会取消确认。
3. 无待手工题的学生无需确认。
4. 全部待手工题都已确认、且任务已结束后，可公开试卷。

给分台列出的题目包括：编程题、参考答案为空的题，以及关闭自动批改后的填空题。进行中即可给分；已公开后不能再改分。

## 8. 成绩分析

左侧选进行中或已结束的任务。有交卷后右侧即出数据大屏：人数、平均/最高/最低/中位、及格率、分数段、按班统计等。点指标可进入学生成绩表或题目分析。点已交卷学生可查看其试卷。

「中位 / 标准差」：中位数是已交卷总分排好后正中间那个位置的分（落在两人之间时按比例插值）；标准差是分数相对平均分的典型起伏。「变异系数」是标准差除以平均分，显示为百分比，用来看相对离散。副标题「四分位 a ~ b」是 25% 分位到 75% 分位，表示中间那一半人的分数大致落在这个区间。

分数段默认按总分 60 / 70 / 80 / 90 / 95 分成 6 段，可在页面上改 5 个分界。成绩构成按优秀+ / 优秀 / 良好 / 及格 / 不及格五段互斥统计，分界可改及格分、良好分、优秀分。

题目分析按大题折叠，标题带正确率、得分率、均分。**智能实时组卷**任务不提供题目分析。

可下载成绩 CSV（Excel 能直接打开中文）。

## 9. 学生作答

1. 打开教师给出的地址，建议带任务参数：`/student.html?t=任务ID`。
2. 填写班级（可空）、姓名或学号（至少一项）。同班重名时必须填学号。
3. 进入后开始计时。答案约每 15 秒自动保存；刷新或换机（同一学生校验通过后）继续上次进度。
4. 允许提前交卷时可以点「交卷」；禁止时等到结束或等教师打开开关。
5. 考试提交后只显示已提交。练习提交后立即出分析。教师公开后，考试学生可看逐题对错：选择题会列出选项，并标出「你的选择」和「正确答案」。

身份不全时页面不会展示试卷。名单中没有该学生会进不去。

## 10. 推荐上课流程

1. 导入题库 HTML，抽查几道答案。
2. 导入名册。
3. 组一份固定试卷，预览调分，按需开关自动批改。
4. 建考试任务，勾名单，记下学生链接。
5. 发布，口述局域网地址，打开监控。
6. 学生作答过程中可收卷；要结束本场时点结束任务。
7. 在试卷批改里给待批改题打分，对该生点提交确认，然后公开。
8. 在成绩分析里看大屏，需要时导出 CSV。

## 11. 常见问题

**学生打不开页面**

确认教师机防火墙放行 8080，学生访问的是局域网 IP 而不是 `127.0.0.1`。讲台页会列出可用地址。

**导入后填空答案丢了括号**

请使用英文括号 `()` 写函数调用。中文括号 `（说明）` 会被当成注释去掉。改完题库后，已交卷不会自动重批，需要教师重新处理该次成绩。

**导出 HTML 里「答案：A」发绿**

规范要求答案用黑体真实粗体。重新导出即可；不要把答案设成宋体加粗。

**预览题目和学生卷面不一样**

固定卷：预览关闭乱序以便核分，学生按组卷时冻结的卷面作答。智能实时组卷：每位考生都会重抽。

**改了分值但学生卷没变**

已生成的学生快照不回溯。调分只影响尚未发卷的预览和之后新进入的实时组卷。

**删不掉某道题**

该题已被已发布任务的试卷快照引用。

**禁止提前交卷时学生没有交卷按钮**

这是预期行为。教师可在进行中随时打开「允许提前交卷」，未提交的学生页立即生效。

**关掉自动批改后原来的自动分还在吗**

只影响填空。关闭后填空的自动分不会带进给分台，须重新点色块。再打开会按参考答案重判已交填空，并取消已确认的批改。单选/多选/判断不受影响。

**填空答案和参考差几个空格**

判分会去掉空白，`i**2` 与 `i ** 2` 视为相同。多个可接受答案用 `|`、「或」或顿号 `、` 分隔。

**选择题预览里选项出现两遍**

导入时会从题干里裁掉内联的 `A. B. C. D.` 行，选项只出现在选项区。重新导入或保存题目后即生效。
