# 教室在线考试系统文档

教师机运行单一服务进程，同时提供讲台网页、学生网页和 REST API。数据保存在本机 SQLite。单选/多选/判断有参考答案即自动批改；填空可开关自动或手工；编程题始终由教师给分。

## 文档

| 文件 | 说明 |
|---|---|
| [设计文档.md](./设计文档.md) | 架构、模块、数据、组卷、判分、接口与部署 |
| [使用文档.md](./使用文档.md) | 启动、讲台六模块、学生作答、常见问题 |
| [题库规范化格式.md](./题库规范化格式.md) | 题库 HTML 导入/导出必须遵守的格式规范 |
| [题库规范化格式.html](./题库规范化格式.html) | 规范原文（浏览器打开即为黑白试卷样式） |

讲台入口：`/teacher.html`。学生入口：`/student.html?t={任务ID}`。

教室 Windows 10 / 11（64 位）可使用 `dist/exam-windows-x64.zip`：解压后双击 `start.bat`，浏览器打开 `http://127.0.0.1:8080/teacher.html`。
