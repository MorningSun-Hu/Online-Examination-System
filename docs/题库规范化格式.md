# 题库格式化规范

本文件对应规范原文 [题库规范化格式.html](./题库规范化格式.html)。教室考试系统导入与导出题库均按此规范处理。

## 一、文档总体要求

- **编码**：UTF-8。
- **语言**：`<html lang="zh-CN">`。
- **标题**：`<title>` 用中文概括文档内容，如「Python 程序设计基础练习 200 题（含答案）」「蓝桥杯Python青少组初赛试题（5份）」。
- **纯黑白风格**：不使用彩色背景、渐变、图片、阴影、图标；所有文字与线条均为纯黑 `#000`，背景纯白 `#fff`。
- **无外部依赖**：不使用 JavaScript、不引用外部字体或图片，全部使用系统字体，保证离线与打印可用。

## 二、颜色规范

| 用途 | 颜色值 | 说明 |
|---|---|---|
| 所有文字 | `#000` | 包括标题、正文、列表、代码、答案、来源说明、对勾符号 |
| 页面背景 | `#fff` | 纯白 |
| 边框与分隔线 | `#000` | `h1`、`h2` 下边框，`pre` 边框，`hr` 分隔线均为 1px 实线纯黑 |
| 代码块背景 | 无（透明） | 不加任何背景色 |

- 在 `:root` 中声明 `color-scheme: light`，防止浏览器暗色模式或自动反色把黑色文字改成灰白/深灰。
- 显式对所有文字元素（`html, body, h1, h2, h3, p, li, div, pre, small, strong, span, ol, ul, hr`）设置 `color: #000`，不依赖继承。

## 三、字体规范

| 用途 | 字体栈 | 说明 |
|---|---|---|
| 正文（段落、列表、选项、来源说明） | `"SimSun", "Songti SC", serif` | 宋体，衬线风格 |
| 标题与加粗元素（`h1`、`h2`、`h3`、`strong`、`.answer`） | `"SimHei", "Microsoft YaHei", "PingFang SC", sans-serif` | 黑体/雅黑，有真实粗体字重，避免宋体合成加粗产生墨绿/紫灰彩色抗锯齿 |
| 代码块（`pre`） | `"Courier New", monospace` | 等宽字体 |
| 对勾符号（`.check-mark`） | `"Segoe UI Symbol", "Arial Unicode MS", "DejaVu Sans", Arial, sans-serif` | 避免宋体下「✓」显示成根号 |

- 在 `body` 上开启字体平滑：`-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale;`，关闭亚像素渲染，消除加粗文字彩边。
- 加粗元素统一用 `font-weight: bold`，正文不加粗。

答案行必须用黑体，不能用「宋体 + 加粗」。宋体没有真实粗体，浏览器合成描边后，「答案：A」会呈现深绿色或紫灰色。

## 四、布局规范

- `body`：`max-width: 800px; margin: 2em auto; padding: 0 1em;`，页面居中，两侧留白。
- 行高：`line-height: 1.8`。
- 标题层级：
  - `h1`：`1.4em`，居中，下边框 `1px solid #000`，`padding-bottom: 0.3em`。
  - `h2`：`1.2em`，`margin-top: 2.2em`，下边框 `1px solid #000`，`padding-bottom: 0.2em`。
  - `h3`：`1.05em`，`margin-top: 1.5em`。
- 试卷之间用 `<hr>` 分隔：无边框，`border-top: 1px solid #000`，`margin: 2em 0`。
- 试卷末尾用 `<p><small>来源：……</small></p>` 标注出处。

## 五、组件样式规范

| 组件 | 类名/标签 | 样式 |
|---|---|---|
| 题目容器 | `.question` | `margin: 0.8em 0` |
| 选项 | `.options` | `margin: 0.2em 0 0.2em 1.5em`，左缩进 1.5em |
| 答案 | `.answer` | `margin: 0.2em 0 0.8em 1.5em`，黑体，`font-weight: bold` |
| 代码块 | `pre` | `"Courier New", monospace`；无背景；`border: 1px solid #000`；`padding: 0.5em`；`white-space: pre-wrap` |
| 对勾符号 | `.check-mark` | 仅设置符号字体，`font-weight: normal` |
| 来源说明 | `small` | 正文宋体，颜色 `#000` |

## 六、内容格式约定

1. **试卷标题**：用 `h2`，格式为「试卷N：年份 + 赛事名称 + 组别」。
2. **题型分类**：用 `h3`，格式为「一、选择题」「二、编程题」「二、判断题」「三、填空题」等。
3. **每道题**：用 `<div class="question">` 包裹，内部依次为：
   - 题目描述：`<p>第N题 ……</p>`
   - 代码（如有）：`<pre>……</pre>`
   - 选项（选择题）：`<div class="options">A. ……　B. ……　C. ……　D. ……</div>`
   - 答案：`<div class="answer">答案：X</div>`
   - 编程题参考答案：`<div class="answer">参考答案：<br><pre>……</pre></div>`
4. **选项分隔**：同一行选项之间用全角空格 `　` 或 `&nbsp;&nbsp;&nbsp;&nbsp;` 分隔。
5. **编程题题目标题**：用 `<strong>第N题 题目名</strong>`。
6. **HTML 实体**：代码或文本中的 `<`、`>` 必须写成 `&lt;`、`&gt;`；对勾用 `&#10003;`；连续空格用 `&nbsp;`。
7. **判断题答案**：正确用 `<span class="check-mark">&#10003;</span>`，错误用 `×`；判断题标题中「正确填『✓』」也同样用 `.check-mark` 包裹。
8. **填空题**：题干中用 `________` 表示空位，答案写在「答案：」之后；多答案用 `|` 分隔。含代码的填空题可用 `<pre>` 展示代码框架。
9. **编程题样例**：样例输入与样例输出写在同一行。
10. **来源标注**：每份试卷末尾用 `<p><small>来源：……</small></p>` 注明出处。

## 七、风格定位

- 整体风格为**黑白试卷打印稿**：纯文字、无装饰、无彩色、无图片。
- 正文宋体、标题与答案黑体，接近传统纸质试卷。
- 代码块用等宽字体并加黑色细边框。
- 答案统一加粗，便于对照批改。
- 页面宽度固定 800px 居中，适合屏幕阅读与 A4 打印。

## 八、兼容性与可访问性

- 声明 `color-scheme: light`，防止暗色模式自动改色。
- 所有文字元素显式指定 `color: #000`。
- 加粗元素使用有真实粗体的字体，避免合成加粗产生彩色抗锯齿。
- 对勾符号使用符号字体，避免在宋体下显示成根号。
- 不依赖任何外部资源，离线打开与打印均保持黑白一致。

## 九、系统导入导出约定

与本仓库实现对齐的补充约定：

- 题型标题含「判断」→ 判断题；含「填空」→ 填空题；含「编程」→ 编程题；含「选择」→ 按答案字母数量判定单选或多选。
- 导出始终按规范结构重新序列化（`h1` 题库名、`h3` 题型、`.question` / `.options` / `.answer`），下载文件名使用题库名。
- 填空答案中的 ASCII 括号 `()` 会保留（如 `print("Hello")`、`random.randint(1, 100)`）；中文括号 `（）` 视为注释并剥掉。多答案用 `|`、「或」或顿号 `、` 分隔。
- 往返只要求语义字段一致（题型、题干纯文本、选项、答案、来源），不要求空白与实体写法逐字节相同。
- 列表题从 DOM 文本取题干和选项；序列化 `inner_html` 时文本节点重新转义 `&lt;` / `&gt;`，避免 `print("a<b")` 被当成标签截断。
- 选择题抽出 `.options` 或内联选项后，`stem_html` 不再保留 `A. B. C. D.` 行。
